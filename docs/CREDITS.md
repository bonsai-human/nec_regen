# 使用素材とライセンス

実装計画書 第11章の方針に従い、本プロジェクトで使う素材は
**自作、または CC0 / パブリックドメイン**のもののみとする。
原作の名称・ロゴ・キャラクター・マップ・グラフィック・音楽・効果音は一切使用しない。

素材を追加したら、必ずこの表に記録すること。
